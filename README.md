# Star Skipper

Star Skipper is a small browser mini game where you pilot a tiny ship through drifting meteors and collect stars for bonus points.

## Play

Open `outputs/star-skipper.html` in any modern browser.

## Controls

- Move left: `Left Arrow` or `A`
- Move right: `Right Arrow` or `D`
- Start from menu: click `Start Game`
- Touch screens: use the on-screen left and right buttons

## Features

- Standalone HTML, CSS, and JavaScript
- No build step or dependencies
- Keyboard and touch controls
- Local best score saved in the browser
- Practice mode with slower, more forgiving meteors
